Vergleichswerte (optional)

      
Optionale Vergabe gesamtregionaler Vergleichswerte. Hierüber sind regionale Gesamtwerte als Summe oder Durchschnittswerte hinterlegbar.

      
Beim initialen Anlegen von Indikatoren können noch keine Vergleichswerte hinterlegt werden. Zur Wahrung der Datenkonsistenz ist dies ausschließlich über die Editiermaske für Indikatoren-Metadaten möglich.
