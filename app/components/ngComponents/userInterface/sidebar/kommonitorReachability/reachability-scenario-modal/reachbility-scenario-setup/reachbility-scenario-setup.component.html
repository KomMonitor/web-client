Name und Datenquelle

Geben Sie einen Namen für das Szenario ein und wählen Sie die Punktedatenquelle, für die die Erreichbarkeit berechnet werden soll.

Beispiel: Kitas_2022_5min_10min_15min_zu_Fuß

Wählen Sie eine Punktedatenquelle und einen Zeitpunkt. Mit der Option ‘-- leerer neuer Datensatz --’ legen Sie eine neue, leere Datenquelle an, um neue Punkte hinzuzufügen.
